## Таблица атрибутов JSON

| Атрибут / настройка | Что делает | Пример |
|---------------------|------------|--------|
| [JsonPropertyName("name")] | Задаёт имя поля в JSON | "name" вместо "Name" |
| [JsonIgnore] | Поле не попадает в JSON | Пароли, внутренние поля |

## Главные выводы

**1. Что такое сериализация и десериализация**

Сериализация — это превращение объекта C# в JSON строку. Десериализация — это превращение JSON строки обратно в объект C#. В ASP.NET Core этим занимается библиотека System.Text.Json.

**2. Зачем нужен [JsonIgnore] — реальный пример**

Этот атрибут скрывает поле от отправки клиенту. Пример: у пользователя есть пароль, который не должен попадать в JSON ответ.

```csharp
public class User
{
    public string Name { get; set; }
    [JsonIgnore]
    public string Password { get; set; }
}
```

**3. Почему enum лучше сериализовать строкой, а не числом**

Число непонятно клиенту: 0, 1, 2 — что это? Строка читаема: "Marvel", "DC". Плюс при добавлении новых значений в enum числовые индексы могут сломать совместимость.

**4. Что изменилось в ответе после настройки CamelCase**

Поля стали с маленькой буквы. Было: "RealName", "CreatedAt". Стало: "realName", "createdAt". Это стандарт JSON, которого ждут фронтенд разработчики.
